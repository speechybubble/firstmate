# Brief CLI feature map

This deliberately small map covers three user-facing scaffold paths.
It makes no claim about worker launch, supervision, or other Firstmate features.

- [Ship modes](ship.md) - explicit delivery mode and worker workflow routing.
- [Scout report](scout.md) - report delivery and worker workflow routing.
- [Invalid mode](invalid-mode.md) - refusal without a successful artifact.

Use the parent [verification recipe](../SKILL.md) for launch, doctor, evidence, and cleanup.
